# 习题解析

> 本目录为《拓扑序：从能带拓扑到量子纠缠》各章"本章习题"的配套解析，与正文**逐题对应**。

## 使用说明

1. **逐题对应**：每个 `NN-习题解析.md` 与教材第 NN 章末"本章习题"一一对应，题号沿用教材 `N.k` 编号。
2. **题型处理**：计算题给完整推导（关键步骤不跳步）；概念题给分步论证；开放题给论证主线并指明可深入的方向。
3. **公式编号**：解析中出现的公式编号沿用教材正文记号 (N.x)，如 (3.7) 即教材第 3 章第 7 式；跨章引用亦注明章号。
4. **公式排版**：显示公式一律使用多行 `$$` 块（不使用单行 `$$...$$`），行内公式用 `$...$`。
5. **数值题**：涉及数值的题目逐步手工核算并在解析中注明过程与结果。
6. **勘误标注**：教材题目或正文公式的疑似错误，在对应题内以 `> ⚠️ 勘误提示` 标注；各册勘误数量汇总见本页索引表及各册末行。
