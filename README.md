# Book of Topological Order（拓扑序教材）

《拓扑序:从能带拓扑到量子纠缠》——面向凝聚态研究生的研究生教材（初稿）。

本书系统介绍拓扑序（topological order）理论：从能带拓扑与几何相位出发，经分数量子霍尔效应、任意子与编织统计、精确可解模型（toric code、Kitaev 蜂窝模型、string-net）、纠缠刻画（拓扑纠缠熵与纠缠谱）、对称性保护拓扑相（SPT）、范畴论语言（模张量范畴、Drinfeld 中心）、任意子凝聚与高阶凝聚，到张量网络（MPS/PEPS/MPO）与共形场论的联系。

## 内容来源

本书全部内容基于 38 篇英文原始文献撰写（详见《参考文献.md》），不引用任何二手中文材料。第 13 章《实现与探测》在此基础上另引一批实验与评述文献，其中出处尚待逐条核实者以脚注（※）形式给出，不进正式引用编号。主要文献包括：

- 文小刚（X.-G. Wen）系列:拓扑序奠基文献（Wen 1990）、FQH 综述（Wen 1995）、量子序（Wen 2002）、Zoo（Wen 2017）、多体场论教材（Wen 2004）
- Kitaev 两篇原始文献:toric code 与容错量子计算（2003）、蜂窝模型与 16 重方式（2006）
- Nayak et al. 非阿贝尔任意子 RMP 综述（2008）
- Levin-Wen 弦网凝聚（2005）
- Chen-Gu-Liu-Wen 群上同调分类（2012）
- Kong-Zhang《An invitation to topological orders and category theory》及高阶凝聚理论
- 张量网络系列（VMC 综述、Orús 讲义、Schuch-Cirac 系列、MPO 系列）
- CFT 三篇（Calabrese-Cardy、Ginsparg、Gaberdiel）

## 建议路线

第 1-2 章按需快速通过 → 第 3-4 章建立概念 → 第 5-6 章掌握工具 → 第 7 章（纠缠）与第 8 章（SPT）→ 第 9 章进入数学框架 → 第 10 章通向研究前沿 → 第 11 章（张量网络）可并行阅读 → 第 12 章（CFT）→ 第 13 章（实现与探测）收束全书。

## 习题解析

配套 `习题解析\` 目录提供 12 册共 80 题逐题解析（第 1-12 章各一册），与正文各章"本章习题"逐题对应：计算题给完整推导，概念题给分步论证，开放题给论证主线；解析中发现的教材疑似错误以 ⚠️ 标注（勘误汇总见该目录 README 的索引表）。
